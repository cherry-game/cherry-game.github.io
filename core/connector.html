连接器 ​

连接器负责监听端口、接受客户端连接，并把连接交给网络解析器（parser）处理。连接器本身也是组件，跟随框架的生命周期启动和关闭。

支持的连接器 ​

连接器构造函数TCP说明
WebSocketcconnector.NewWS(address, opts...)WebSocket浏览器 / H5 客户端常用
TCPcconnector.NewTCP(address, opts...)TCP原生客户端、压测机器人
HTTP Server——见 gin 组件
HTTP Client——见 extend/http，不属于连接器
KCP——尚未实现

HTTP Server 在哪

Cherry 核心仓库不提供 HTTP Server 连接器。需要 HTTP 服务时使用 gin 组件，它以组件形式提供完整的 HTTP 服务能力（路由、静态文件、中间件）。

连接器接口 ​

go
type IConnector interface {
	IComponent
	Start()
	Stop()
	OnConnect(fn OnConnectFunc)
}

type OnConnectFunc func(net.Conn)

内置连接器的组件名：

连接器组件名
TCPtcp_connector
WebSocketwebsocket_connector

使用方式 ​

连接器不会单独注册，而是挂在网络解析器（parser）上。Application.Startup() 会把 parser 里的连接器自动注册为组件：

go
agentActor := pomelo.NewActor("user")
agentActor.AddConnector(cconnector.NewWS(":34590")) // 监听 34590
app.SetNetParser(agentActor)
app.Startup() // 连接器随之启动

一个 parser 可以挂多个连接器，同时监听多个端口：

go
agentActor.AddConnector(cconnector.NewWS(":34590"))    // 给 H5 客户端
agentActor.AddConnector(cconnector.NewTCP(":10011"))   // 给原生/压测客户端
app.SetNetParser(agentActor)

选项 ​

go
import cconnector "github.com/cherry-game/cherry/net/connector"

// 启用 TLS
conn := cconnector.NewWS(":443",
	cconnector.WithCert("server.crt", "server.key"),
)

// 调整连接 channel 缓冲大小
conn := cconnector.NewTCP(":10011",
	cconnector.WithChanSize(1024),
)
选项说明
WithCert(certFile, keyFile)启用 TLS/SSL 证书
WithChanSize(size)设置连接 channel 缓冲大小

底层 GetListener(certFile, keyFile, address) 会根据是否传证书决定监听方式，传了证书就是 TLS 监听。

完整示例 ​

以单节点聊天室为例，用 WebSocket 连接器对外提供服务：

go
func main() {
	app := cherry.Configure(
		"../../config/demo-chat.json",
		"room-1",
		true,               // isFrontend = true 才能使用连接器
		cherry.Standalone,
	)

	agentActor := pomelo.NewActor("user")
	agentActor.AddConnector(cconnector.NewWS(":34590"))

	agentActor.SetOnNewAgent(func(newAgent *pomelo.Agent) {
		newAgent.AddOnClose(func(agent *pomelo.Agent) {
			// 连接关闭
		})
	})

	app.SetNetParser(agentActor)
	app.Startup()
}

isFrontend 必须为 true

cherry.Configure(path, nodeID, isFrontend, mode) 的第三个参数是 isFrontend。只有前端节点才允许使用连接器——它决定了框架是否初始化客户端连接相关的组件。gate、room 这类直接面向客户端的节点都要传 true；game、center 这类纯逻辑节点传 false。

连接建立后 ​

连接建立后，解析器会把它包装成 Agent，并触发 SetOnNewAgent 回调。在那里可以：

  • 注册连接关闭回调 AddOnClose
  • 为每条连接创建子 Actor（见 Actor 模型 - 子 Actor）
  • 设置数据路由函数

数据到达后的解析与路由细节见 网络数据包。
