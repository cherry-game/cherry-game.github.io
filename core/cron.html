cron 组件 ​

把 robfig/cron/v3 封装成 Cherry 组件，按 cron 表达式或固定间隔定时执行函数。

安装 ​

bash
go get github.com/cherry-game/components/cron@latest

模块路径已变更

组件已从 cherry 主仓库迁出。旧路径 github.com/cherry-game/cherry/components/cron 已废弃，请使用 github.com/cherry-game/components/cron。

注册组件 ​

组件本身不读取任何配置，定时规则全部在代码里注册。

go
import (
	"github.com/cherry-game/cherry"
	cherryCron "github.com/cherry-game/components/cron"
)

func main() {
	app := cherry.Configure("./config/profile.json", "game-1", false, cherry.Cluster)

	app.Register(cherryCron.New()) // 注册 cron 组件

	app.Startup()
}

New() 可选地接收 cron.Option：

go
app.Register(cherryCron.New(cron.WithChain(cron.SkipIfStillRunning(nil))))

默认实例已经带上了 WithSeconds()（支持秒级表达式）和 panic 恢复。

添加定时任务 ​

go
import cherryCron "github.com/cherry-game/components/cron"

// cron 表达式（支持秒级，共 6 段）
id, err := cherryCron.AddFunc("0 30 9 * * *", func() {
	// 每天 9:30:00
})

// 每天固定时刻
cherryCron.AddEveryDayFunc(func() {
	now := ctime.Now()
	clog.Infof("每天 %d 点 %d 分 %d 秒运行", now.Hour(), now.Minute(), now.Second())
}, 17, 32, 5) // 每天 17:32:05

// 每小时固定时刻
cherryCron.AddEveryHourFunc(func() {
	clog.Infof("每小时第 %d 分执行", ctime.Now().Minute())
}, 5, 0) // 每小时第 5 分 0 秒

// 固定间隔
cherryCron.AddDurationFunc(func() {
	clog.Info("每分钟执行一次")
}, 1*time.Minute)

// 自定义 Job
cherryCron.AddJob("0 0 4 * * *", myCronJob{})

// 自定义 Schedule
cherryCron.Schedule(mySchedule{}, myCronJob{})

API ​

方法说明
New(opts ...cron.Option) cfacade.IComponent创建组件
Init(opts ...cron.Option)手工初始化（非组件方式时使用）
AddFunc(spec string, cmd func()) (cron.EntryID, error)按 cron 表达式注册
AddEveryDayFunc(cmd func(), hour, minutes, seconds int) (cron.EntryID, error)每天固定时刻
AddEveryHourFunc(cmd func(), minute, second int) (cron.EntryID, error)每小时固定时刻
AddDurationFunc(cmd func(), duration time.Duration) (cron.EntryID, error)固定间隔
AddJob(spec string, cmd cron.Job) (cron.EntryID, error)注册 cron.Job 实现
Schedule(s cron.Schedule, cmd cron.Job) cron.EntryID自定义调度规则
Entries() []cron.Entry列出所有任务
Entry(id cron.EntryID) cron.Entry查询单个任务
Location() *time.Location时区
Remove(id cron.EntryID)移除任务
Start() / Run() / Stop()启动 / 阻塞运行 / 停止

组件生命周期里 Init() 会自动调用 Start()，OnStop() 会自动调用 Stop()——用组件方式注册时不需要手工调用。

优先用 Actor 定时器

定时任务如果只涉及某个 Actor 的内部状态，用在 Actor 里的 定时器 更合适——回调会回到该 Actor 的 goroutine 执行，天然串行，不用考虑并发。cron 组件更适合跨 Actor 的全局任务（如整点结算）。

完整示例 ​

go
package main

import (
	"time"

	"github.com/cherry-game/cherry"
	clog "github.com/cherry-game/cherry/logger"
	cherryCron "github.com/cherry-game/components/cron"
)

func main() {
	app := cherry.Configure("./config/profile.json", "game-1", false, cherry.Standalone)

	app.Register(cherryCron.New())

	// 每天凌晨 4 点做数据清理
	cherryCron.AddEveryDayFunc(func() {
		clog.Info("开始每日数据清理")
	}, 4, 0, 0)

	// 每 30 秒打印一次状态
	cherryCron.AddDurationFunc(func() {
		clog.Infof("当前时间：%v", time.Now())
	}, 30*time.Second)

	app.Startup()
}

AddEveryDayFunc / AddEveryHourFunc / AddDurationFunc 这几个快捷方法不需要记 cron 表达式语法，日常业务足够用。
