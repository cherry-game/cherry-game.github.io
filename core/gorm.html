gorm 组件 ​

基于 gorm 管理多组 MySQL 数据实例。一个节点可以按「组」组织多个数据库连接，并按需只加载自己关心的那些。

安装 ​

bash
go get github.com/cherry-game/components/gorm@latest

注册组件 ​

go
import (
	"github.com/cherry-game/cherry"
	cherryGORM "github.com/cherry-game/components/gorm"
)

func main() {
	app := cherry.Configure("./config/profile.json", "game-1", false, cherry.Standalone)

	app.Register(cherryGORM.NewComponent())
	app.Startup()
}

配置 ​

gorm 需要两处配置配合才能生效，缺一不可：

  1. db 段：定义数据库连接
  2. 当前节点的 __settings__.db_id_list：声明这个节点要连哪几个库
json
{
    "node": {
        "game": [
            {
                "node_id": "game-1",
                "address": ":10860",
                "__settings__": {
                    "db_id_list": {
                        "center_db_id": "center_db_1"
                    }
                }
            }
        ]
    },

    "db": {
        "center_db_group": [
            {
                "enable": true,
                "db_id": "center_db_1",
                "dsn": "",
                "db_name": "dev_center",
                "host": "127.0.0.1",
                "user_name": "dev_user",
                "password": "dev_password",
                "max_idle_connect": 4,
                "max_open_connect": 8,
                "log_mode": true
            }
        ]
    }
}

db.<group>[n] 字段 ​

字段类型默认值说明
db_idstring—逻辑库 id，必填，与 db_id_list 的值匹配
enablebooltrue为 false 时直接 panic
dsnstring""为空时用内置模板拼接
db_namestring—库名
hoststring—形如 127.0.0.1:3306
user_namestring—用户名
passwordstring—密码
max_idle_connectint4最大空闲连接数
max_open_connectint8最大连接数
log_modebooltrue为 true 时开启 db.Debug()

内置 DSN 模板：

%s:%s@(%s)/%s?charset=utf8&parseTime=True&loc=Local
└─┬─┘ └─┬─┘ └─┬─┘ └─┬─┘
user  pass  host  dbname

需要特殊参数（如时区、字符集）时，直接在 dsn 里写完整连接串，就会覆盖模板。

enable 与 enabled 不是同一个字段

db 段里的开关字段叫 enable，而 node 段里的叫 enabled。写错不会报错——框架会静默使用默认值 true，导致你以为关掉了某个库其实还在连。

db_id_list 缺失只警告不报错

如果节点的 __settings__ 里没有 db_id_list，组件只会打一条 warning 然后跳过初始化。之后调用 GetDb 会拿到 nil。数据库连不上时先检查这里。

使用数据库 ​

go
// 1. 取组件
gormComponent, ok := app.Find(cherryGORM.Name).(*cherryGORM.Component)
if !ok || gormComponent == nil {
	clog.Panicf("[component = %s] not found.", cherryGORM.Name)
}

// 2. 从节点私有配置里读逻辑库 id
centerDbID := app.Settings().GetConfig("db_id_list").GetString("center_db_id")

// 3. 按逻辑 id 取 *gorm.DB
db := gormComponent.GetDb(centerDbID)
if db == nil {
	clog.Panic("center_db_1 not found")
}

在 Actor 里初始化数据库连接：

go
type ActorDB struct {
	cactor.Base
	centerDB *gorm.DB
}

func (p *ActorDB) AliasID() string {
	return "db"
}

func (p *ActorDB) OnInit() {
	gormComponent, ok := p.App().Find(cherryGORM.Name).(*cherryGORM.Component)
	if !ok || gormComponent == nil {
		clog.Panicf("[component = %s] not found.", cherryGORM.Name)
	}

	centerDbID := p.App().Settings().GetConfig("db_id_list").GetString("center_db_id")
	p.centerDB = gormComponent.GetDb(centerDbID)
}

API ​

方法说明
NewComponent() *Component创建组件
GetDb(id string) *gorm.DB按逻辑库 id 取单个连接
GetHashDb(groupID string, hashFn HashDb) (*gorm.DB, bool)在一组库里按哈希规则选一个
GetDbMap(groupID string) (map[string]*gorm.DB, bool)取整组的连接表

HashDb 用于分库场景，由你决定分片规则：

go
type HashDb func(dbMaps map[string]*gorm.DB) string

db, ok := gormComponent.GetHashDb("game_db_group", func(dbMaps map[string]*gorm.DB) string {
	// 按玩家 id 取模选库
	keys := make([]string, 0, len(dbMaps))
	for k := range dbMaps {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	return keys[uid%int64(len(keys))]
})

定义表结构 ​

go
type UserBindTable struct {
	Id       int64  `gorm:"primaryKey;column:id"`
	Uid      int64  `gorm:"column:uid"`
	Pid      string `gorm:"column:pid"`
	BindTime int64  `gorm:"column:bind_time"`
}

// 显式指定表名
func (UserBindTable) TableName() string {
	return "user_bind"
}
