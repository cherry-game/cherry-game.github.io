关于 Cherry ​

Cherry 是一款用 Go 语言实现的游戏服务端框架，具有高性能、可伸缩、分布式的特点。它帮你省去搭建业务框架的工作——不用重复造轮子，把精力放在游戏逻辑本身。

框架基于 NATS 进行消息分发，依托 Goroutine 的优势实现 Actor 模型，按业务需要可以构建成千上万个 Actor 实例，方便玩家与玩家之间、模块与模块之间通信。

核心思路 ​

概念说明
Actor 模型每个 Actor 独占一个 goroutine 串行处理消息，Actor 内部状态无需加锁
组件管理用组件组合功能，框架统一管理生命周期，按需注册
通信 & 集群节点间基于 NATS 通信，支持本地配置 / NATS 主从 / etcd 三种发现方式
连接器组件化的网络连接器，自带 TCP、WebSocket
网络数据包内置 Pomelo 与 Simple 两种协议，序列化支持 JSON / Protobuf
Profile 配置一份 JSON 配置管理所有参数，支持多环境与文件拆分

两个模式 ​

go
// 单机模式：单进程开发调试，不需要任何外部服务
app := cherry.Configure(path, "room-1", true, cherry.Standalone)

// 集群模式：多进程多节点，需要 NATS
app := cherry.Configure(path, "game-1", false, cherry.Cluster)

单机模式适合开发期；集群模式下框架会自动注册集群组件与发现服务组件，节点之间通过 NATS 互相通信、互相发现，服务可以横向扩展。
