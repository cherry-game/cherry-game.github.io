安装 NATS ​

NATS 是 Cherry 集群模式的节点间通信中间件。单机模式（Standalone）不需要安装。

什么时候需要 ​

场景是否需要 NATS
单节点开发（cherry.Standalone）不需要
多节点集群（cherry.Cluster）需要
单节点聊天室不需要
多节点集群需要
使用 etcd 发现服务 的集群需要（集群通信仍走 NATS）

任选一种安装方式 ​

项目自带（Windows，最省事） ​

示例仓库里已经放了一份 Windows 版可执行文件：

examples/3rd/nats-server/nats-server.exe

直接双击运行即可。

官方安装指南 ​

https://docs.nats.io/running-a-nats-service/introduction/installation

Docker ​

bash
docker run -p 4222:4222 nats:latest

或参考：https://docs.nats.io/running-a-nats-service/introduction/installation#installing-via-docker

安装包下载 ​

https://github.com/nats-io/nats-server/releases

Homebrew ​

bash
brew install nats-server

验证服务 ​

启动后窗口显示下面的内容代表启动成功：

Listening for client connections on 0.0.0.0:4222

默认监听 4222 端口，与 Cherry 默认配置里的 nats://127.0.0.1:4222 一致。

正式环境请用集群部署

单机 NATS 一旦挂掉，整个集群就失去通信能力。生产环境请部署 NATS 集群，至少 3 个节点。
