编写一个 Cherry 服务器 ​

这篇教程从零开始，一步步搭出一个可运行的 Cherry 服务端，说明每一步在做什么。

前置准备 ​

按顺序完成环境准备：

  1. 安装 Go（>= 1.24）
  2. 安装开发工具
  3. 安装 NATS —— 只有集群模式需要；下面的例子先用单机模式，可以跳过

1. 创建项目 ​

bash
mkdir my-game && cd my-game
go mod init my-game
go get github.com/cherry-game/cherry@latest

2. 写配置 ​

在项目下创建 config/profile.json：

json
{
    "env": "dev",
    "debug": true,
    "print_level": "debug",

    "node": {
        "room": [
            {
                "node_id": "room-1",
                "address": ":34590",
                "enabled": true,
                "__settings__": {
                    "ref_logger": "room_log"
                }
            }
        ]
    },

    "logger": {
        "room_log": {
            "level": "debug",
            "enable_console": true,
            "enable_write_file": false
        }
    }
}

这份配置声明了一个节点：id 是 room-1，类型是 room（由 node 段的键决定），监听 :34590。

nodeID 与 nodeType

node 段的键是节点类型（nodeType），数组里每项的 node_id 是具体节点 id。

启动时传入的 nodeID 会被用来在配置里查找匹配项，匹配成功后就同时确定了节点类型、监听地址和 __settings__。详细规则见 Profile 配置。

3. 写入口 ​

创建 main.go：

go
package main

import (
	"github.com/cherry-game/cherry"
	clog "github.com/cherry-game/cherry/logger"
)

func main() {
	// 读取配置并创建应用
	app := cherry.Configure(
		"./config/profile.json", // profile 配置路径
		"room-1",                // 本节点 id
		false,                   // isFrontend：不需要接收客户端连接
		cherry.Standalone,       // 单机模式
	)

	// 注册业务 Actor
	app.AddActors(&ActorHello{})

	// 启动（会阻塞在这里，直到收到退出信号）
	app.Startup()

	clog.Info("server stopped")
}

cherry.Configure 的四个参数决定了应用的基本形态：

参数说明
pathprofile 配置文件路径，相对进程工作目录
nodeID本节点唯一 id，框架用它反查节点类型和私有配置
isFrontend是否前端节点。只有前端节点能挂连接器接收客户端连接
nodeModecherry.Standalone（单机）或 cherry.Cluster（集群）

4. 写第一个 Actor ​

创建 actor_hello.go：

go
package main

import (
	cfacade "github.com/cherry-game/cherry/facade"
	clog "github.com/cherry-game/cherry/logger"
	cactor "github.com/cherry-game/cherry/net/actor"
)

type ActorHello struct {
	cactor.Base
	count int // 只被本 Actor 的 goroutine 访问，无需加锁
}

// AliasID 决定 Actor 路径：room-1.hello
func (p *ActorHello) AliasID() string {
	return "hello"
}

func (p *ActorHello) OnInit() {
	// 注册可被调用的方法
	p.Local().Register("say", p.say)
	p.Remote().Register("stats", p.stats)

	// 每 5 秒执行一次
	p.Timer().Add(5*time.Second, func() {
		clog.Infof("hello actor tick, count = %d", p.count)
	})
}

func (p *ActorHello) say(msg string) string {
	p.count++
	return "hello, " + msg
}

func (p *ActorHello) stats() int {
	return p.count
}

// 返回 (false, true)：不再把消息转发给子 Actor
func (*ActorHello) OnLocalReceived(_ *cfacade.Message) (bool, bool) {
	return false, true
}

Actor 路径怎么来的

AliasID() 返回 hello，加上节点 id room-1，这个 Actor 的路径就是 room-1.hello。

其它 Actor 用这个路径找到它：Call("room-1.hello", "say", "world")。

5. 跑起来 ​

bash
go run .

看到启动日志、并且每 5 秒打印一次 tick 就说明成功了。按 Ctrl+C 退出。

6. 对外提供服务 ​

前面的例子没有接收客户端连接。要让客户端能连进来，需要三步：加连接器、加解析器、加路由。

创建协议定义 ​

创建 protocol.go：

go
package main

type LoginRequest struct {
	Nickname string `json:"nickname"`
}

type LoginResponse struct {
	Code int `json:"code"`
}

type ChatMessage struct {
	Content string `json:"content"`
}

改造入口 ​

go
func main() {
	app := cherry.Configure(
		"./config/profile.json",
		"room-1",
		true,               // 改为 true：前端节点才能挂连接器
		cherry.Standalone,
	)

	// 默认序列化是 protobuf，网页调试用 JSON 更方便
	app.SetSerializer(cserializer.NewJSON())

	// 创建 Pomelo 解析器，挂一个 WebSocket 连接器
	agentActor := pomelo.NewActor("user")
	agentActor.AddConnector(cconnector.NewWS(":34590"))

	agentActor.SetOnNewAgent(func(newAgent *pomelo.Agent) {
		newAgent.AddOnClose(func(agent *pomelo.Agent) {
			if !agent.IsBind() {
				return // 没登录过的连接不用通知业务
			}
			clog.Infof("[uid = %d] disconnected", agent.UID())
		})
	})

	// 设置数据路由
	agentActor.SetOnDataRoute(onDataRoute)

	app.SetNetParser(agentActor)

	app.AddActors(&ActorHello{}, &ActorRoom{})

	app.Startup()
}

写路由函数 ​

go
func onDataRoute(agent *pomelo.Agent, route *pmessage.Route, msg *pmessage.Message) {
	session := agent.NewSession(msg.ID)

	// 登录消息允许未绑定 uid
	if msg.Route == "room.room.login" {
		targetPath := cfacade.NewChildPath(agent.NodeID(), route.HandleName(), session.Sid)
		pomelo.LocalDataRoute(agent, route, msg, targetPath)
		return
	}

	// 其余消息必须先绑定 uid
	if !session.IsBind() {
		agent.ResponseCode(session, ccode.SessionUIDNotBind, true)
		return
	}

	targetPath := cfacade.NewPath(agent.NodeID(), route.HandleName())
	pomelo.LocalDataRoute(agent, route, msg, targetPath)
}

路由字符串是三段式 room.room.login：节点类型.处理者名字.方法名。

写房间 Actor ​

go
type ActorRoom struct {
	cactor.Base
	users map[int64]string // uid -> nickname
}

func (p *ActorRoom) AliasID() string {
	return "room" // 路径：room-1.room
}

func (p *ActorRoom) OnInit() {
	p.users = make(map[int64]string)
	p.Local().Register("login", p.login)
	p.Local().Register("chat", p.chat)
}

7. 切换到集群模式 ​

单机跑通后，改集群模式只需要换一个参数并启动 NATS：

go
app := cherry.Configure(
	"./config/profile.json",
	"room-1",
	true,
	cherry.Cluster, // 改为集群模式
)

并在 config/profile.json 里加上集群段：

json
{
    "cluster": {
        "discovery": { "mode": "nats" },
        "nats": {
            "prefix": "node",
            "master_node_id": "master-1",
            "address": "nats://127.0.0.1:4222"
        }
    }
}

框架会自动注册集群组件与发现服务组件。之后跨节点调用就是透明的——Call / CallWait 会根据目标路径自动选择本地投递还是经 NATS 转发。

完整的多节点结构见 多节点集群。

业务做起来后，通常还需要这些组件：

需求组件

MySQLgorm
MongoDBmongo

注册方式都一样，加到 Startup() 之前即可：

go
app.Register(
	cherryCron.New(),
	cherryGORM.NewComponent(),
)
